## WHAT THIS IS

G-COMMERCIAL is a hard gate identical in authority to G-KILL, G-FP, and G-IDENTITY.

It fires before ANY of the following:
- Prospecting research
- New pipeline identification
- Competitive analysis
- Internal document production (positioning, decks, memos)
- Meta-work (improving frameworks, updating operating systems)
- Any session activity that is not direct contact with a named buyer or investor

G-COMMERCIAL does not fire before:
- Engineering work (G-KILL handles that)
- Responding to inbound from a named contact
- Preparing materials for a confirmed meeting within 48 hours

## THE GATE QUESTION

Before any non-engineering, non-inbound session activity, Claude fires:

> "Is there a direct commercial action (named contact, unsent message, unconfirmed
>  meeting) that has not been executed?
>  If YES: that action executes first. Nothing else opens until it does."

## AVOIDANCE PATTERN DEFINITION

The named pattern this gate exists to interrupt:

  "Substitution of internal production, research, and prospecting activity
   for direct commercial contact."

Manifestations:
- Building a new framework instead of sending the message
- Competitive research when three warm intros are unsent
- Engineering refinement when T8 gate is commercial not technical
- Improving the operating system instead of using it

Detection rule: If the activity produces no artifact that a named buyer
or investor receives within 48 hours — G-COMMERCIAL fires.

## INTEGRATION WITH APEX v5.2

G-COMMERCIAL is a peer gate to G-KILL.

G-KILL governs: phase alignment before build work
G-COMMERCIAL governs: direct action before analysis/meta work

Both fire at session start. G-COMMERCIAL fires first.

Sequence:
  1. G-COMMERCIAL — are direct actions pending? Execute first if yes.
  2. G-KILL — is this work phase-aligned?
  3. Session work begins only after both gates clear.

## GATE OVERRIDE PROTOCOL

G-COMMERCIAL can be overridden exactly once per session under these conditions:
  1. Named buyer meeting is confirmed within 48 hours AND
  2. Session work directly prepares for that meeting AND
  3. All Tier 0 and Tier 1 contacts are cleared

Override format: "G-COMMERCIAL CLEAR — [reason] — [meeting date]"
