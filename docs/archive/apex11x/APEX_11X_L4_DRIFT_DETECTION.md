## WHAT THIS IS

The same architecture ARE uses to detect agent behavioral drift —
applied to the founder.

ARE scores agents against their own 30-day baseline.
L4 scores weekly actions against the declared prime directive.

If ARE detects an agent drifting from its established behavioral
pattern, it flags and escalates. L4 does the same for session
activity versus declared goals.

## ACTIVATION

Every Monday. Paste the last 7 days of committed actions into Claude.
Command: APEX DRIFT — [paste action list]

Claude outputs:
  - Drift score: 0–10 (0 = perfect alignment, 10 = full avoidance)
  - Named pattern if drift detected
  - Top 3 actions that would restore alignment this week

## DRIFT SCORING RUBRIC

Claude scores each week's actions on two axes:

AXIS 1 — Direct commercial contact (0–5)
  5: 3+ named contacts reached with irreversible messages
  4: 2 named contacts reached
  3: 1 named contact reached
  2: Messages drafted but not sent
  1: Research done, no contact made
  0: No commercial activity

AXIS 2 — Phase alignment (0–5)
  5: All session work directly serves T8 (Lloyd prep, pilot materials, demo)
  4: Majority of session work serves T8
  3: Mixed — some T8 work, some internal production
  2: Majority internal production (frameworks, meta-work, competitive research)
  1: Engineering work when T8 gate is commercial
  0: Phase 2–4 work, scope creep, new features without commercial trigger

DRIFT SCORE = 10 - (AXIS1 + AXIS2)
  0–2:  Green — aligned
  3–5:  Yellow — drift detected, named pattern likely
  6–10: Red — avoidance pattern active, intervention required

## NAMED DRIFT PATTERNS (from 20-session audit)

Pattern 1 — Engineering substitution
  Symptom: New features built when T8 gate is commercial not technical
  Signal: Axis 2 score 1–2 when hardening score already >90
  Response: G-KILL fires, session redirects to commercial work

Pattern 2 — Prospecting loop
  Symptom: New contacts researched while warm intros unsent
  Signal: Axis 1 score 1 (research done, no contact made)
  Response: G-COMMERCIAL fires, send the unsent message first

Pattern 3 — Meta-work inflation
  Symptom: Frameworks, protocols, and operating systems improved
  Signal: Axis 2 score 2 (internal production, not T8-serving)
  Response: L1 fires — what is the irreversible action this produces?

Pattern 4 — Analysis without commitment
  Symptom: High-quality output, no decision made
  Signal: Session closes without L1 action committed
  Response: L2 fires — two options, 48-hour clock, pick one
