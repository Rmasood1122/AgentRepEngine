# FP Scenario Specifications

This directory is reserved for spec-first behavioral specifications.
Each specification must be committed BEFORE the corresponding scenario
implementation in tests/fp_scenarios/.

## Current Status

The 150-scenario corpus (LEG-001–LEG-100 + BND-001–BND-050) was
constructed before this protocol was formalized. Inline specifications
exist in boundary_scenarios.go as structured comments.

Formal per-scenario spec files will be created for all corpus
expansion beyond 150 scenarios (spec-first protocol required).

See: docs/enterprise/fp-corpus-independence.md Section 2.3
